## 🎯 Conseils d'utilisation

### Pour les publications LinkedIn :

1. **Poster aux bons horaires** : Mardi-Jeudi, 8h-9h ou 17h-18h
2. **Répondre à TOUS les commentaires** dans les 2 premières heures
3. **Mettre le lien en commentaire** (pas dans le post) pour l'algo
4. **Taguer 2-3 personnes pertinentes** qui pourraient être intéressées
5. **Republier le contenu** sous forme de carrousel 2-3 semaines après

### Pour les DM :

1. **Personnaliser systématiquement** le nom de l'entreprise et le contexte
2. **Ne jamais vendre dans le premier message** — apporter de la valeur
3. **Follow-up max 2 fois** avec 3-4 jours d'intervalle
4. **Accepter le "non"** gracieusement — la relation long terme compte
5. **Tracker dans un CRM** (Notion, HubSpot) pour ne pas relancer 2x

### Séquence recommandée :

```
J0 : Publication LinkedIn
J1-J3 : Réponse aux commentaires + engagement
J3 : DM aux personnes qui ont liké/commenté
J7 : DM froid vers cibles identifiées
J10 : Follow-up DM
J14 : Nouvelle publication sur le même thème (angle différent)
```
