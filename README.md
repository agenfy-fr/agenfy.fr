Site corporate d'[Agenfy](https://www.agenfy.fr), cabinet de conseil tech (Data, IA, Cloud, Conseil), construit avec Next.js.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Supabase · pnpm

## Getting Started

```bash
pnpm install
pnpm dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

Autres commandes :

```bash
pnpm build   # build de production
pnpm start   # démarrer le build de production
pnpm lint    # ESLint
```
